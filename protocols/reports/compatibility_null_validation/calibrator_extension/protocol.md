# Immutable exploratory saved-prediction protocol
All analyses A–E are exploratory, retrospective, conditional on saved fits and fitted calibration maps. No training, checkpoint loading, forward inference or test-selected choices. Independent human review is missing.
Roster: eight existing FD001–4 LSTM/hybrid equal-search groups; eight TCN/GRU equal-search groups (40 fits); four original hybrid groups (20 fits, their own per-seed calibration partitions); saved five-seed extra controls for each subset: lstm_gpu, hybrid_gpu, gru_gpu, tcn_gpu, lstm_cv, hybrid_cv. Each group averages its five fixed fits. Missing files are reported, never replaced by inference. Additional CV controls included to avoid ambiguity about extra controls.
Official-test final windows only. Unique engine key = subset + official-test engine ID; train/calibration keys are separate. Check truth against official RUL files and IDs across fits. Calibration endpoints retain their recorded own partitions. Training offsets come only from recorded metadata; TrainOff is fixed, not fitted to calibration labels.
A: event raw RUL <=30; quantile levels .05,.5,.95. L=max(level for q<=30, default 0), U=min(level for q>30, default 1). Projection clips p to [L,U]. Compare raw, projection, TrainOff, Temp, TrainOff+Temp, Platt, Isotonic, Beta and each of the six then projection. Fit each map separately per saved fit on its own calibration engines only. Temp minimizes mean calibration NLL with inverse temperature [0.1,10], including endpoints and identity. Platt logistic affine logit; Beta logistic affine (log p,-log(1-p)); L2 penalty 1e-6 on slopes, intercept unpenalized, L-BFGS-B maxiter 2000; Isotonic increasing with endpoint clipping. Single-class calibration uses smoothed constant (positives+.5)/(n+1), except TrainOff. Optimization failures retained as unavailable. NLL clips at 1e-15. ECE5 uses per-fit/per-method label-free quintile edges collapsed for ties, frozen across draws; ECE10 fixed width tenths. Average per-fit scores, never score averaged probabilities.
Inference: 2000 paired engine-cluster percentile bootstrap draws, seed 2026110201 + subset index, shared across all fits/methods/groups. Calibration maps fixed during test bootstrap; CIs condition on calibration estimates, do not include calibration estimation uncertainty. Per-group scores and method-minus-raw differences with 95% CIs. Pooled: average available fit losses within each distinct engine, then average engines (707 total), same synchronized draws stratified by subset; ECE pooled as engine-count-weighted group ECE, equal group weights within subset. Report group and pooled counts, model counts and calibration counts. No multiplicity correction; no confirmatory inference.
B: projection-minus-raw Brier and NLL sign and CI for EVERY group. Helps if upper CI<0; hurts if lower CI>0; otherwise unresolved. Count all groups separately for each metric.
C: improvement = raw Brier minus projected Brier, per engine-fit; distance=max(L-p,p-U,0). Fixed bins d=0,(0,.05],(.05,.2],>.2. Report conditional mean improvement with paired cluster CI, distinct engines and engine-fit counts per bin. No bin changes.
D: strict p>U and p<L frequencies; mean signed projected-minus-raw change, base rate, raw/projected mean p, absolute base-rate gaps, and gap change. Report CIs and unique engines. No tolerance changes.
E: all added groups (also existing for completeness): outcomes (q50-min(raw RUL,125))^2 and raw Brier. Flag d>0. OLS with fit-specific intercepts, cubic capped RUL/125 adjustment; extended adds cubic raw p and indicator 20<=raw RUL<=40. Also report RUL-only adjustment restricted to 20–40 band. Refit regression for each engine bootstrap. Pseudoinverse rcond 1e-10, flag estimable only if null-space flag row norm<1e-6; undefined draws counted. Coefficient, percentile CI, own mean, coefficient/mean and CI/mean, approximate MDE=(1.959964+.841621)*bootstrap SD, MDE/own mean. No causal interpretation or dropping adverse/nonidentifiable groups.
Save input hashes before computation and verify after; protocol SHA256 checked on every run. Save software versions and available current AI/session/build identifiers; unavailable exact served checkpoint explicitly marked unavailable. Report every result, including unfavorable and undefined results. No outcome, threshold, subgroup or criterion changes after this lock. Implementation corrections may fix code only to match this protocol and must be logged.
